# MediGuide AI 💎✨ — Premium Medical Assistant

**MediGuide AI** is a high-fidelity, professional medical recommendation assistant designed specifically for the Indian pharmaceutical market. It uses the **Groq Llama-3 70B** model to provide instant, structured medical advice, dosage information, and localized pricing—all wrapped in a stunning holographic glassmorphism interface.

## 💠 Features
- **Ultra-Glassmorphism UI**: A premium "Gemstone" design system with deep blurs, animated mesh gradients, and interactive hover physics.
- **AI-Powered Diagnostics**: Instant analysis of 15+ common symptoms with localized Indian medicine recommendations.
- **Full-Stack Security**: Zero-Trust client architecture with a hardened Vercel backend proxy to keep API keys 100% hidden.
- **Smart Utilities**: Automatic Indian Pricing (INR), dosage/timing instructions, and one-click search history.
- **Dual Theme**: Perfectly tuned "Arctic Light" and "Deep Night" modes.

## 🚀 Quick Start (Local Setup)

1.  **Clone the Repository**:
    ```bash
    git clone https://github.com/yourusername/MediGuide-AI.git
    cd MediGuide-AI
    ```

2.  **Environment Setup**:
    Create a `.env` file in the root directory and add your Groq API Key:
    ```env
    GROQ_API_KEY=your_groq_api_key_here
    ```

3.  **Run with Vercel CLI**:
    ```bash
    npm install -g vercel
    vercel dev
    ```
    Open `http://localhost:3000` to see your premium assistant in action.

## 🛡️ Production Deployment
This project is optimized for **Vercel**. 
- Push to GitHub.
- Import the project into Vercel.
- Add `GROQ_API_KEY` to Vercel Environment Variables.
- **Deploy!**
